# SimpleEnglish for Vale

Do not edit these files by hand. They are generated by
`bin/render-vale`. Vendor the directory, or point Vale's
StylesPath at vale/styles.

This edition enforces 63 of the 67 built-in rules.

## Hand-written checks

These rules need part-of-speech matching or negation, which the
generator does not translate. Each has a hand-written check in
vale/overrides:

- `SE_ACTIVE_VOICE`
- `SE_CONDITION_FIRST`
- `SE_ING_AFTER_COMMA`
- `SE_KEEP_THAT`
- `SE_PRESENT_PERFECT`

`SE_CONDITION_FIRST` is degraded: Vale's tagger does not mark
imperative verbs reliably, so it misses some cases.

Sequence checks also match case-sensitively, so a
sentence-initial verb can escape.

## Not in this edition

- `SE_NO_EMDASH`: Vale checks match words, not punctuation.
- `SE_NO_SEMICOLON`: Vale checks match words, not punctuation.
- `SE_SENTENCE_TOO_LONG`: A counting rule. It lives in the se CLI, not in styles.
- `SE_PARAGRAPH_TOO_LONG`: A counting rule. It lives in the se CLI, not in styles.

The se CLI enforces the full set. The source of truth is
rules/simple-english.xml. This edition serves pipelines
that already run Vale.
