## [0.4.0] - 2026-10-01

### Added

- Daemon handshake: `GET /` on the daemon reports its version, pid, and digests.
- The first lint after a gem update warns about an outdated daemon. Run `se serve --detached` to restart it.
- `se version` prints the gem version, so the matching container image tag is `v` plus it
- `se serve --detached` replaces a running daemon and runs the new one in the background, like the auto-started daemon

### Changed

- `se serve` stops a running se daemon and takes over its port, so reloading after a gem update is one command. It used to fail with PortInUse.
- `se setup` reports each check as it completes: whether LanguageTool was downloaded or already cached, which java it picked and from where (SE_JAVA, PATH, or Homebrew), and the smoke test result
- `se setup` no longer takes `--dir`. Set `SE_CACHE_DIR` instead; it already covered every use.
