## [0.8.1] - 2026-10-13

### Fixed

- Lint files with non-ASCII characters from clients that run without a locale, such as Claude Desktop. Claude Desktop showed the failure as an invalid response.
- Handle MCP requests that name non-ASCII paths instead of killing the server. Claude Desktop showed the failure as an invalid response.
- Lint non-ASCII text piped into `se lint -` instead of crashing on `invalid byte sequence`.
